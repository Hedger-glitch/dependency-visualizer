# Dependency Graph Visualizer (Вариант 20)

Инструмент визуализации графа зависимостей для менеджера пакетов Python (pip).

##Возможности
На текущий момент реализовано:
- Собственный CLI-парсер аргументов с валидацией (без использования сторонних библиотек).
- **Режим `local`**: чтение и парсинг локального файла `requirements.txt`.
- **Режим `online`**: получение прямых зависимостей пакета с сервера PyPI (с использованием зеркала) по сети.
- **Режим `test`**: чтение тестового графа зависимостей из файла.
- Построение графа зависимостей алгоритмом DFS без рекурсии.
- Учет максимальной глубины анализа (`--depth`) и обработка циклических зависимостей
- Вычисление порядка загрузки зависимостей.
- Обработка ошибок ввода (неверный тип, отсутствие обязательных флагов, неверный URL).

## Установка
Для работы требуется Python 3.10 или выше. Сторонние библиотеки пока не используются.
```bash
pip install -r requirements.txt
```

## Запуск
Программа запускается через скрипт run.bat для Windows и через run.sh для остальных

## Параметры командной строки:
- -p, --package - Имя анализируемого пакета (обязательно)
- -r, --repo - Путь к локальному файлу requirements.txt (обязательно для режима local)
- -m, --mode - Режим работы: local или online (обязательно)
- -v, --version - Версия пакета (по умолчанию latest)
- -d, --depth - Максимальная глубина анализа (по умолчанию 5)
- -a, --ascii - Вывод в виде ASCII-дерева (пока не реализованно)
- -o, --order - Вывести порядок загрузки зависимостей

## Пример 1. Локальный режим
Анализ файла зависимостей из тестового репозитория:
```bash
./run.sh -p numpy -r data/my_test_repo/requirements.txt -m local
```

## Пример 2. Онлайн-режим
Получение прямых зависимостей пакета request с PyPI
```bash
./run.sh -p requests -m online
```

## Тестовый режим с выводом графа и порядка загрузки
Анализ графа из файла с обработкой циклов и выводом порядка установки:
```bash
./run.sh -p A -r data/test_graph.txt -m test -d 3 --order
```
